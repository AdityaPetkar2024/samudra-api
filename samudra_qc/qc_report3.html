Samudra: Profile Quality Control Report

Generated 06 September 2026 · Aditya Petkar, Bangalore Institute of Technology

Purpose

This report presents results from an automated profile-level quality control pipeline applied to Indian Ocean Argo float profiles and ship-based CTD casts. The tests follow the Argo Quality Control Manual for CTD and Trajectory Data, version 3.9 (ADMT, February 2025).

Both data sources are parsed into a single common profile representation, so the same quality control code runs unchanged on Argo floats and on CTD casts. This was a design requirement rather than a convenience: applying consistent checks across both instrument types is what makes combined use of the two datasets tractable.

Data sources

Argo: profiles obtained from INCOIS GDAC as raw NetCDF and ingested into PostgreSQL. Pressure, temperature and salinity are used at their reported levels; no interpolation is applied before QC.

CTD: casts from the NOAA World Ocean Database, read at observed depth levels. WOD reports depth in metres, converted here to pressure in dbar following the standard UNESCO relation so that both sources present identical units to the tests.

Tests implemented

TestDescriptionCriterion
2Impossible date Observation date not in the future; after 1997 for Argo, after 1900 for CTD
3Impossible location Latitude within ±90°, longitude within ±180°
6Global range Temperature -2.5 to 40.0 °C; salinity 2.0 to 41.0 PSU; pressure below -5.0 dbar bad, -5.0 to -2.4 dbar probably bad
13Stuck value All valid values in a profile identical, with at least five valid levels required

Quality control flags follow the Argo convention (Reference Table 2): 1 good, 2 probably good, 3 probably bad, 4 bad, 9 missing. A flag set by one test is never lowered by a subsequent test.

Limitations and work in progress

The four tests implemented here are the coarsest of the real-time suite. They detect values that are physically impossible or sensors that have failed outright, but they do not detect subtler problems. In particular the following tests are not yet implemented:

  • Test 8: pressure increasing (monotonicity)
  • Test 9: spike test
  • Test 11: gradient test
  • Test 14: density inversion
  • Test 25: MEDD (median of extended deviations)
  • Climatology consistency against a reference atlas
  • Salinity drift detection, which requires delayed-mode analysis

Density inversion and the spike test are the next priorities, as they are the tests most likely to catch profiles that would otherwise contaminate a gridded product.
